# Hafeef Modern Portfolio

Modern true-black React + TypeScript portfolio with animated terminal visual, responsive navigation, skills, projects, experience and contact sections.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize
- Main content: `src/App.tsx`
- Design/animations: `src/styles.css`
- Page metadata: `index.html`

The portfolio content is based on the supplied CV.
